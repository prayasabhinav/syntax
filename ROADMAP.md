# Roadmap

What SYNTAX could do next, in no fixed order. Each item waits on a decision of Prayas's where one is named.

1. **Two formats, on formats.teachsite.org**: *a syntax* (how to write one down: the kind of thing, its element types, whether each holds one or several, its elements) and *a game* (one game described in a syntax). Drafted as proposals; published only when he approves.
2. **More syntaxes.** Each named by its primary name, each read from an instance that holds it. Candidates are his to choose; whether teachsite, or a course, is one is an open question.
3. **The syntax as a file.** Every syntax page already serves its data (`/board-game.json`). A written format for that file would let a new instance be built from a syntax instead of the other way round.
4. **Entities in more than one syntax.** A thing can be described in two syntaxes at once; showing where they meet.
5. **Records described in the record syntax.** The record syntax is listed from 0.3.0, read from Zariia; nothing is described in it yet. Once Zariia's simulator is live, records made with it could be listed the way board games are.
