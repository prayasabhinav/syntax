The personhood syntax

It breaks up a piece of work in which language work and judgement work are both in play, by who holds each part of it. It has 4 element types and 17 elements, and a personhood described in it is one choice of elements from each type.

Instances

  • Split-Domain Cognition: the principle that language work and judgement work are unlike kinds of thinking, kept apart in the service of the intent of the person doing the work
  • Koher: Split-Domain Cognition's child: free, open-source tools built on the principle

Element types and elements

intent holds one

What the work is for. It comes first and stays with the person doing the work; the sentence that states it is never a model's.

the person
the one doing the work
an animal
the animal whose life it is; it holds its own intent, which nobody states for it, neither a model nor a person. It is partially excluded: intent is the only part it holds
other people
people other than the one doing the work
a model under negotiation thing
a thing, not a person: a model, holding this part only where that was negotiated and set up for this work, its answers held by code
code thing
a thing, not a person: rules fixed in advance as a written standard and run as a program anyone bound by them can read

language holds one

The language work: reading, gathering, describing, writing. It is held by people unless it has been negotiated and set up otherwise.

residue holds one

What the description handed to the judgement does not capture: named and left visible as unrated, never folded into the verdict or denied.

Left out

Things are excluded: a model and code are things, so they have no personhood, and they hold a part only as tools a person set up. Animals are partially excluded: an animal holds intent, and is excluded from language, judgement and residue, because those are written or ruled, and an animal's signals are read for structure, never translated.
