Kinds of things, broken into parts

A kind of thing can be broken into the same parts every time. SYNTAX writes those parts down: the element types a kind of thing has, and the elements of each type. Once they are written, each thing of that kind can be described as a choice of elements, compared with others, and made by choosing differently.

The words

syntax
how one kind of thing breaks into element types and elements. A syntax is named by the primary name of the kind of thing it breaks up, never by a tool or a brand.
element type
one group of parts every thing of that kind has. It holds one element or several.
element
one part.
entity
one particular thing of that kind, described as its choice of elements.
instance
a tool built on a syntax. Each syntax's page names its instances and the things described in it.
