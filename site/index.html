SYNTAX

A kind of thing can be broken into the same parts every time. SYNTAX writes those parts down: the element types a kind of thing has, and the elements of each type. Once they are written, each thing of that kind can be described as a choice of elements, compared with others, and made by choosing differently.

The words

syntax
how one kind of thing breaks into element types and elements. A syntax is named by the primary name of the kind of thing: board game.
element type
one group of parts every thing of that kind has, such as victory condition. It holds one element or several.
element
one part, such as race to finish.
entity
one particular thing of that kind, described as its choice of elements: Pig is a board game of push your luck, race to finish and take turns, among others.
instance
a tool built on a syntax. boardgameBuilder is an instance of the board game syntax.

Syntaxes

  • board game: 8 element types, 86 elements; instance boardgameBuilder
